# NetMap — Network Discovery Dashboard

NetMap is a real-scan-only Streamlit application for reviewing saved Nmap XML, comparing two real scans, and exporting CSV/HTML reports. It never starts a network scan. The current light slate-and-blue interface is retained.

## Launch on Windows

Open PowerShell in this project folder and run:

```powershell
py -m pip install -r requirements.txt
py -m streamlit run dashboard.py
```

You can also double-click `Run-Demo.bat` (legacy launcher filename); it now only starts the application and does not generate demo data. On each new session, NetMap first asks you to select a valid Nmap XML scan from `scans/` or upload one. The dashboard appears only after successful validation and loading. Use **Change scan** in the sidebar to return to the input screen.

## Use the application

- **Overview** shows metrics, chart, host/port records, and exports for the one currently loaded scan.
- **Host Discovery**, **Ports & Services**, and **Reports & Exports** use that same loaded scan; they do not offer independent data sources.
- **Comparison** requires two valid real Nmap XML scans. Select both from `scans/` or upload separate Baseline and After files.
- If there is no scan in the new session, no metrics or sample data are shown. Invalid XML is rejected. Valid empty scans show empty states.

Fixtures under `sample_data/` remain for automated parser/report tests only. The production dashboard does not load or display them. Existing `outputs/demo-*` files, if present from an earlier version, are not read or generated by the current app.

## Scan data and privacy

Keep real Nmap scans, packet captures, exported reports, and screenshots out of this public repository. They can reveal private addresses, hostnames, services, or unrelated traffic. Use local files or sanitized synthetic fixtures when reviewing the application.

## Tests

```powershell
py -m unittest discover -s tests -v
py -m py_compile netmap.py dashboard.py tests/test_netmap.py tests/test_dashboard_overview.py
py -m pip check
```

The test suite includes Streamlit AppTest coverage for the scan-selection gate, saved and uploaded XML, scan changes, invalid/empty XML, comparison input requirements, and export controls. See `IMPLEMENTATION_STATUS.md` and `FINAL_CHECKLIST.md` for results and remaining manual checks.
