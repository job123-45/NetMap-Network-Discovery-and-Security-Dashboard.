NETMAP — START HERE

1. Read README.md, then SECURITY.md before using the optional scan commands.
2. Install: py -3 -m venv .venv; .\.venv\Scripts\Activate.ps1; py -m pip install -r requirements.txt
3. Run the synthetic end-to-end demonstration: py netmap.py demo
4. Start the local UI: py -m streamlit run dashboard.py
5. Click Load synthetic demonstration for a safe, clearly labeled walkthrough.
6. Upload an Nmap XML file to inspect real authorized observations locally; no network scan starts in the dashboard.
7. Run tests with: py -m unittest discover -s tests -v
8. Real scans, reports, screenshots, and packet captures should remain local unless sanitized and intentionally reviewed for publication.
